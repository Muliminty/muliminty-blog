# 快速开始 - 5 分钟创建你的第一篇内容

## 第一步：创建 Issue

访问：https://github.com/Muliminty/muliminty-blog/issues/new

## 第二步：选择内容类型

### 📝 创建文章（长文）

```
标题：我的第一篇技术文章

正文：
## 为什么写博客

记录学习过程，分享技术心得...

## 我的技术栈

- React
- Next.js
- TypeScript

## 未来计划

持续输出高质量内容...

标签：article, 随笔
```

### 💭 创建动态（短文）

```
标题：（留空或简短标题）

正文：
今天学会了 Next.js 的 ISR 功能，
可以实现静态页面的增量更新，太强了！🚀

标签：tweet, Next.js
```

## 第三步：添加标签

**必须添加以下之一：**
- `article` → 显示在文章列表
- `tweet` → 显示在动态流

**可选添加分类标签：**
- `React`、`Vue`、`CSS`
- `教程`、`笔记`、`踩坑`

## 第四步：提交

点击 **Submit new issue** 按钮

## 第五步：查看效果

- 文章列表：http://localhost:3000/posts
- 动态流：http://localhost:3000/tweets

---

## 🎯 标签对照表

| 标签 | 显示位置 | 适用场景 |
|------|----------|----------|
| `article` | `/posts` | 技术文章、教程、深度分析 |
| `tweet` | `/tweets` | 碎片思考、快速笔记、日常分享 |

## 💡 提示

1. **标签大小写不敏感**：`Article` 和 `article` 效果相同
2. **可以同时添加多个标签**：`article, React, 教程`
3. **没有标签的 Issue 不会显示**：必须添加 `article` 或 `tweet`
4. **关闭的 Issue 会隐藏**：Close issue 即可下线内容
